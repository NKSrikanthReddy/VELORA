# Velora — AI-Powered Medical Record Consolidation & Clinical Briefing Platform

Velora is a patient-controlled medical record consolidation and clinical briefing platform built with a **Python FastAPI** backend, **Next.js 16 (React 19 / TypeScript)** frontend, and an integrated **AI/OCR Document Processing Engine**.

---

## Architecture Overview

```text
Document Upload (PDF/Image)
        │
        ▼
PDF & OCR Text Extraction (Pillow / pypdf)
        │
        ▼
Document Classification & AI Entity Extraction
        │
        ▼
Medical Concept Normalization & Conflict Detection
        │
        ▼
Structured Patient Timeline & Medical Briefing Generation
        │
        ▼
Doctor Clinical Q&A ("Ask My Records") with Evidence Citations
```

## Quick Start Guide

### 1. Environment Setup
Copy `.env.example` to `.env`:
```bash
cp .env.example .env
```

### 2. Backend Setup & Demo Seed
Install Python dependencies and seed the demo database with fictional medical records:
```bash
python -m pip install -r requirements.txt
python scripts/seed_demo.py
```

Start the FastAPI backend server:
```bash
uvicorn app.main:app --reload --port 8000
```
- **Swagger Documentation**: [http://localhost:8000/docs](http://localhost:8000/docs)
- **ReDoc API Documentation**: [http://localhost:8000/redoc](http://localhost:8000/redoc)

### 3. Frontend Setup
In a new terminal window, navigate to `frontend/`:
```bash
cd frontend
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

## Security & Patient Isolation

- **Role-Based Access Control**: Strict role enforcement (`patient`, `doctor`, `admin`).
- **Patient Control & Access Codes**: Temporary access codes (`MED-XXXXX`) generated by patients for doctor authorization.
- **Instant Access Revocation**: Patients can revoke doctor access at any time (`DELETE /api/patients/{id}/access/{access_id}`), instantly terminating authorization.
- **Safety Guardrails**: Doctor Q&A rejects treatment recommendations and dosage changes, limiting responses to factual medical history summaries with evidence references.
